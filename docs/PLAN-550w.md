## 2. 已经定下来的三条（不再问）

1. **倒计时用诚实时钟**，不压缩：550C 自己的结尾就在日志里打 `[T-00:00:03]…[T-00:00:00]` 的真实秒数，
   "数字互相对得上"是这个移植的招牌。
2. **结尾横幅不复用 550C 的 `#final`**：那个样式里 `box-shadow`/`text-shadow` 硬编码了琥珀
   （`rgba(232,160,32,…)`），照抄等于把暖晕带进 550W。写自己的横幅，全部走 token（四套 scheme 才有意义），
   宽度按"≥ 550C 真机横幅的 0.8×"卡。
3. **发动机改成纵向主体**（见拍 4），月球退成背景上下文。

## 3. 复用什么（"辨识度"就来自这里）

| 复用什么 | 复用方式 |
|---|---|
| 开场 boot stage | **同一份 markup + 同一条 `playBoot()` 时间线**，只换尾字形与字幕。落地方式见下 |
| 接管叙事语汇 | 外观与节奏照搬 550C 的 `.win-popup`/`.wp-title`/`.wp-log`/`.ln`/`#hud-top`/`#hud-bot`/进度条，内容换成月球发动机 |
| 结尾定格 | 同款横幅机制（边框 + 扫入 + 两侧光柱），颜色换成 550W 自己的 |
| 数字自洽 | ID / 遥测 / 进度 / CRC 必须互相对得上，沿用 `enhance` 层那套校验行写法 |

**"开场同源"要重新落地**：`playBoot()` 是 550C `createShow()` 闭包里的私有函数，且硬编码了字幕与尾字形，
所以"只换两处"必须有参数孔。上一版的做法（值得照做）是**生成器 + 构建断言**：手维护一份带两个洞的 boot 模板，
`extract.mjs` 由它产出共享模块，并断言"把洞按 550C 的值填回去必须与 `BOOT_MARKUP` 逐字节相等"。
那条断言当时实测是活的（模板里改一个字节 → `npm run extract` 立刻 exit 1）。550C 自己那份生成文件一个字都不改。

## 4. 尾字形 W：描参考图，不凭印象画

参考图在 **`.render/ref-550w-mark.webp`**（1860×722，已逐像素量过；`.render/` 是 gitignore 目录）：

- 白的 `550`；红字形掩膜 bbox x 860–1381 / y 85–591，色值 `rgb(231,20,27)`；它右边还有一个**白 V**
  （x 1372–1772）。
- 把两块掩膜各自描成闭合轮廓（边界追踪 → Ramer-Douglas-Peucker 1.6px）得到 51 点与 25 点的两条 path，
  用一个 `translate(55.4 3.1) scale(0.3638)` 放进 boot 的 viewBox：高度对齐 `550` 的 187 单位，
  横向**与第三个字形互相穿插**（不是并排挂在右边）。
- 仍是**两条 path**（拆成两个组），于是 `#logo path` 数（6）、组数（5）与 `250 + i*300` 的节拍三方都与 550C 对齐；
  红的身份从第三个字形**挪到尾字形**（第三个字形改回白）。
- 配色候选：① 全红 ② 左红右白 ③ 红 0 + 白 W。**结论倾向 ②**——红掩膜止于 x 1381，而白 V 整块是白的。
  形状已经量好，换配色只是改两个 fill。**开工时让用户在这三张里挑。**

## 5. 开工时的验收口径（沿用，来自上一轮）

- 阶段数 ≥6、总长 18–22s（长于 550C 的 11.5s）；每拍写 `data-phase`；
- 与 550C 同毫秒对比：boot stage 结构逐项相同，只有尾字形组与字幕不同，`#bootText` = `550W SYSTEM BOOT`；
- 550C 逐字节回归（`git diff` 不含 `src/variants/550c/`）；
- 跳过：各阶段真 `Esc` + 真点击都能 <2s 收场，提示不残留，退场后 `activeElement` 不在遮罩上；
- **`long task = 0`、主线程 busy ≤5%**（550C 同法对照）；**帧间隔只作参考**——本机同配置两次跑差 2×，不可复现；
- 四套配色仍给不同 token、结构不变；只用 `sleep()/later()`，`npm run audit:leak` 0 残留；
- 构建门槛：`extract` + `build` + `node --check` ×2 + `git diff --exit-code -- lib/client.js` + `npm run check`。
